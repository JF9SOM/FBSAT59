# トラブルシューティング

まず次を集めてください: アプリのバージョン（ヘルプ > バージョン情報）、OS、無線機/SDR の機種、行った操作、期待した動作と実際の動作、ログ `fbsat59.log`（場所は [index.md](index.md)）。画面下のステータスバーに `RIG: ...` のような短いエラーが出ることがあります。

## アプリが起動しない

- **Windows で「DLL が見つからない」**: DLL 名が `api-ms-win-crt-*.dll` なら OS が Windows 8.1 未満で、FBSAT59 は動きません。Windows をアップグレードしてください。`VCRUNTIME140.dll` や `MSVCP140.dll` なら Microsoft Visual C++ 再頒布可能パッケージ（x64）を入れてください。
- **Ubuntu 以外の Linux の AppImage**: テキスト欄にキー入力できないことがあります（既知の問題）。ターミナルから起動し、出力を報告に添えてください。

## 衛星リストや TLE が空/古い

- インターネット接続を確認し、初回起動後は数分待ってから 衛星 > TLEを更新 を試します。更新スケジュールは ヘルプ > 自動取得ルール。
- 他のサイトは見えるのに CelesTrak/SatNOGS だけタイムアウトする場合、アクセス過多で IP が一時的に制限されている可能性があります。時間をおくか、別回線（スマホのテザリング等）で試してください。
- TLE が無い衛星は追尾できません。衛星 > TLEを手動追加... で追加できます（古くなると警告が出ます）。

## 衛星にトランスポンダーが無い

衛星 > トランスミッターDBを取得 を実行します。SatNOGS に登録が無ければ 衛星 > トランスミッターを追加... で手動追加できます（手動データは自動同期で上書きされません）。

## パス時刻や位置がおかしい

ファイル > QTH設定（緯度・経度の符号、グリッド）、表示 > タイムゾーン（UTC/ローカル）、PC の時計が正しいかを確認します。

## 無線機が接続できない／ドップラー補正が効かない

- 赤の「未接続」: ケーブル・電源・シリアルポート・無線機側 CAT のボーレート・CI-V アドレス（Icom）を確認。ポートを使う他のソフト（WSJT-X、rigctld など）は終了してください。
- 機種選択を確かめてください（FTX-1 と FT-991A は別機種です）。
- 切断後は「Rig に接続」を押し直します。無線機設定を OK で閉じても接続は維持されます。
- アップリンクの無い衛星（テレメトリー専用）では、機種によって周波数が正しく設定されないことがあります（既知の制約）。
- FT4 の送信区間中は、アプリは意図的にリグへ CAT コマンドを送りません。

## SDR が検出されない／接続しても何も起きない

- **Windows**: Zadig で WinUSB を適用して再起動します（getting-started.md 参照）。列挙に出ることはドライバーが正しい証拠ではありません。libusbK は使わないでください。
- USB ポート・ケーブルを変え、給電のないハブは避けます。検出が不安定なときは、まずケーブルの接触を疑ってください。
- **Linux**: SoapySDR モジュールと `scripts/99-fbsat59.rules` の udev ルールを入れます。
- ヘルプ > SDRデバイスのインストール でスキャンと案内が見られます。

## ローテーターが赤の「未接続」

ローテーターが応答していません。電源・ケーブル・ポート・機種を確認します。電源を切ったまま接続を試みた場合は検出できないため、先に電源を入れてください。接続直後の最初の動きは、目標に追いつくためにしばらくかかることがあります（正常）。

## デジタルモードのタブが「未インストール」／デコードされない

- ヘルプメニューから該当コンポーネント（ft8lib、Q65 Library、Direwolf、SatDump、gr-satellites、CW Model）を入れ、求められたら再起動します。
- リグでの FT4/APRS/CW は、無線機設定のサウンドカードに音声が入り、レベルが適切であることが必要です。無線機の音声出力とデータ/パケットモードの設定も確認してください。
- METEOR/HRPT: SatDump が必要です（ヘルプ > SatDump...）。ゲインは手動で設定します（AGC は偽ロックの原因になるため選べません）。信号が弱い、または自動追尾の衛星が違うと画像は出ません。
- Windows で ft8lib のインストールが「ファイルがロックされている」で失敗する場合は、FT4 タブを閉じてアプリを再起動し、再度インストールしてください。

## その他

- 一部の画面文字列は英語のままです（仕様です）。
- Wayland 上の GNOME ではウィンドウ位置の指定が無視されます（アプリ側では直せません）。

## 不具合の報告方法

1. 可能なら一度再現させる
2. https://github.com/JF9SOM/fbsat59/issues で Issue を作成
3. 次を書く: バージョン、OS、無線機/SDR/ローテーターの機種、手順、期待と実際の動作、`fbsat59.log` の該当部分。パスワードや個人情報は載せないでください。

AIヘルプで解決しなかった場合は、AI にこの内容をまとめた Issue 用の文面を作らせ、そのまま貼り付けてください。
