# FT4

FT4 は 7.5 秒周期の高速デジタルモードで、RS-44・JO-97・MO-122 などのアマチュア衛星で使われます。
**通信（Communications）> FT4** から開きます。FT4 トランスポンダーを選ぶと自動で開きます。
符号化・復号は内蔵されており、WSJT-X は不要です。

## 始める前に

- **ft8lib** コンポーネントのインストールが必要です（ヘルプ > ft8lib Installation…）。未導入だとタブに
  「ft8lib is not installed」と出て、FT4 の送受信は無効になります。
- 任意: ヘルプ > FT4 Enhanced Decoder Installation… で、より強力な復号器（受信のみ）を追加できます。
- タブ内の **My Call** と **Grid** を設定します。My Call が空だと送信できません。
- 音声入力を選びます: **Rig Soundcard**（無線機 > 無線機設定 > Sound Card で設定）または **SDR**。
- Rig 1 を接続し、衛星と FT4 トランスポンダーを選びます（周波数はドップラー補正つきで自動設定されます）。
  PTT は無線機経由で制御されます。

## 運用の流れ

1. **Decoded Messages** に、周期ごとの受信結果（時刻・dB・DT・周波数・メッセージ）が並びます。
   局をダブルクリックすると返信の準備が始まり、送信メッセージが自動で入ります。
2. **TX Slot**: 送信する周期（Even／Odd）。通常は相手と逆にします。
3. **TX Audio**（Hz）: 送信する音声周波数。
4. **TX Enable** で送信を有効にすると、次の周期から送信します。**Halt TX** で直ちに停止します。
   **Call CQ** で CQ メッセージを準備します。
5. **Auto-progress**（Yes/No）: QSO が無いときに他局から呼ばれたら、自動で QSO を始めて返信を準備します。
   送信には引き続き TX Enable が必要です。
6. RR73 を受信すると QSO は自動でログされ、73 を送信します。手動で保存するなら **Log QSO**、
   現在の QSO を消すなら **Clear**。
7. **Export ADIF…** で LoTW 互換形式のログを出力します。

## レベルと試験

- **TX Level**（フルスケールからの dB）: 無線機の ALC が振れる、または音が歪むときは下げます。
  機器によっては 20 dB 前後の減衰が必要です。
- **RX Level** は入力レベル（dBFS）です。クリップしないようにします。
- **Tune** はレベル調整用の連続テスト音を送信します。もう一度押すと停止します。送信中は使えません。

## ウォーターフォール

Waterfall ウィンドウに受信音声が表示されます。クリックすると送信の音声周波数を設定できます。
初回はメインウィンドウの上に開き、以降は動かした位置のまま開きます。

## ADC（Audio Doppler Correction／音声ドップラー補正）

衛星のドップラーシフトは、無線機の周波数更新が追いつかない速さで変化します。高仰角（例: RS-44 の
最接近付近）では、7.5 秒の周期の中だけでも誤差が大きくなり、FT4 が復号できなくなります。ADC は補正の
一部を無線機側から、ソフトウェアによる音声側へ移す機能です。FT4 タブの ADC 欄には 2 つのチェックがあります:

- **TX**: 送信中はアップリンク周波数を固定し、ドップラーの変化を送信音声のトーンを動かして追従します。
  オフにすると WSJT-X と同じ固定トーンで送信します。
- **RX**（実験的・既定はオフ）: 無線機の周波数を毎秒ではなく 1 周期に 1 回だけ設定し、残りの差分だけ
  受信音声をシフトしてから復号します。ウォーターフォールには補正後の音声が表示されます（線が真っ直ぐに
  なっていれば補正が効いています）。お使いの構成で RX を有効にできないという表示が出た場合は、オフの
  ままにしてください。

ドップラーの変化率が大きくて復号に失敗するときに使います。変化率が非常に大きい場合（約 55 Hz/s 以上）は
限界があります。詳細は `fbsat59.log` と同じフォルダの `ft4_decode.log`（`adc_rx` で始まる行）に記録されます。

## FT4 のトラブルシューティング

- **何もデコードされない**: 音声入力レベル（RX Level）、無線機のデータ/USB モード、PC の時計の精度
  （DT が小さいこと）、ft8lib のインストールを確認します。
- **ALC が振れる／送信音が歪む**: TX Level を下げます。
- **PTT が動かない**: Rig 1 の接続を確認します（「PTT command failed — check Rig 1 connection」）。
  無線機が送信のままになっている可能性があるときは、無線機本体を確認してください。
- **サウンドカードが使用中**: 同じサウンドカードを別のタブが使っています。そのタブを閉じてください。
- 解決しない場合は `fbsat59.log` と `ft4_decode.log` を添えて GitHub の Issue で報告してください。
